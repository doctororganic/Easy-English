### Part 2: The "Local Mechanic" Hybrid Plan

**Requirements:** No subscriptions, no API keys, no registrations.
**Environment:** Your local VS Code (or IDE) and Terminal.

This hybrid plan takes the **permanent file fixing** from Plan-D and combines it with the **instant feedback** of Plan-Z. It includes a safety backup mechanism so you cannot break your app.

#### Phase 1: The "Safe-Fix" Script (Node.js)

This script will automatically scan your components and upgrade old `onClick` navigation to modern `Link` components. It creates a backup of your files before touching them.

**Action:** Create a new file in your project root called `auto-fixer.js` and paste this code:

```javascript
const fs = require('fs');
const path = require('path');

// 1. CONFIGURATION
const targetDir = './src/components'; // Adjust if your components are elsewhere
const filesToFix = ['FunctionalLanguage.jsx', 'Setbook.jsx', 'Vocabulary.jsx', 'Home.jsx'];

console.log("🛠️  Starting The Local Mechanic Fixer...");

filesToFix.forEach(fileName => {
    const filePath = path.join(targetDir, fileName);
    
    if (fs.existsSync(filePath)) {
        let content = fs.readFileSync(filePath, 'utf8');
        
        // A. CREATE BACKUP (Safety Net)
        fs.writeFileSync(`${filePath}.bak`, content);
        console.log(`💾 Created backup: ${fileName}.bak`);

        // B. FIX 1: Convert onClick navigation to Link components
        // Finds: <div onClick={() => navigate('/path')}>Text</div>
        // Replaces with: <Link to="/path">Text</Link>
        // Note: This is a safe regex pattern for simple navigation
        if (!content.includes('import { Link }')) {
             content = "import { Link } from 'react-router-dom';\n" + content;
        }

        // Fix generic button navigation
        content = content.replace(
            /<div[^>]*onClick=\{\(\) => navigate\(['"]([^'"]+)['"]\)\}[^>]*>(.*?)<\/div>/gs, 
            '<Link to="$1" className="nav-link">$2</Link>'
        );

        // C. FIX 2: Add Stop Propagation to Events
        // Prevents clicks from "bubbling up" and triggering parent elements
        content = content.replace(
            /onClick=\{\(e\) => \{/g, 
            'onClick={(e) => { e.stopPropagation(); '
        );

        // D. FIX 3: Ensure State Updates use Functional Syntax
        // Prevents "stale state" bugs
        content = content.replace(
            /set([A-Za-z]+)\(([^)]+)\)/g, 
            (match, stateName, args) => {
                if (args.includes('prev') || args.includes('=>')) return match;
                return `set${stateName}(prev => ${args})`;
            }
        );

        // Write the fixed content back
        fs.writeFileSync(filePath, content);
        console.log(`✅ Fixed and saved: ${fileName}`);
    } else {
        console.log(`⚠️  File not found: ${fileName} (Skipping)`);
    }
});

console.log("\n🏁 Repair Complete. Restart your server (npm start) to see changes.");
```

**How to run it:**
Open your terminal and type:

```bash
node auto-fixer.js
```

#### Phase 2: The "Universal" Component Templates

Automated scripts sometimes miss complex logic (like the Grade selection). Replace the specific code blocks below manually to guarantee functionality.

**1. The `Setbook.jsx` Grade Selector (Copy & Paste this component)**
This replaces your current grade buttons. It uses URL-based navigation which is bulletproof.

```jsx
// Inside Setbook.jsx
import { Link, useParams } from 'react-router-dom';

const GradeSelector = () => {
  const { grade } = useParams(); // Get current grade from URL

  const grades = [
    { id: 'grade-7', label: 'Grade 7' },
    { id: 'grade-8', label: 'Grade 8' },
    { id: 'grade-9', label: 'Grade 9' }
  ];

  return (
    <div className="grade-selection-container">
      {grades.map((g) => (
        <Link 
          key={g.id} 
          to={`/setbook/${g.id}`}
          className={`grade-btn ${grade === g.id ? 'active' : ''}`}
          style={{ 
            display: 'inline-block', 
            padding: '10px 20px', 
            margin: '5px', 
            textDecoration: 'none',
            backgroundColor: grade === g.id ? '#2563eb' : '#e5e7eb',
            color: grade === g.id ? 'white' : 'black',
            borderRadius: '8px'
          }}
        >
          {g.label}
        </Link>
      ))}
    </div>
  );
};
```

// Inside FunctionalLanguage.jsx
const handlePracticeStart = (section, e) => {
    // CRITICAL: Stop the event from triggering parent clicks
    if(e) {
        e.preventDefault();
        e.stopPropagation();
    }
    // Log for debugging
    console.log('Opening practice for:', section);
    setPracticeMode({
        isOpen: true,
        topic: section
    });
};
