### 1. IELTS Question Generation Prompts[1][2]

**Reading Comprehension Generator**:
```
Generate an IELTS Academic Reading passage and questions:

Topic: {Climate Change/Technology/Education/Health}
Difficulty: {Band 6.0/7.0/8.0}
Length: 800-900 words
Question Types: Mix of True/False/Not Given, Multiple Choice, Matching Headings

Passage Requirements:
- Academic style with complex vocabulary
- Clear paragraph structure (6-8 paragraphs)
- Include statistical data or research findings
- Use formal linking words
- Vocabulary level: Band 7-8 (CEFR C1)

Generate:
1. Complete passage with title
2. 13 questions across 3 types:
   - 5x True/False/Not Given
   - 5x Multiple Choice (A, B, C, D)
   - 3x Matching paragraph headings

3. Answer key with explanations
4. Vocabulary list (15 key academic words with definitions)
5. Time allocation: 20 minutes

Example format:
**Passage:** [Full text]
**Questions 1-5:** True/False/Not Given
**Questions 6-10:** Multiple Choice
**Questions 11-13:** Matching Headings
```

```
Theme: {Environment/Economics/Technology/Health}

Generate:

1. **Word List with Analysis:**
   For each word provide:
   - Word form (noun/verb/adj/adv)
   - IPA pronunciation
   - Band level (6.0/7.0/8.0)
   - Definition (IELTS context)
   - Synonyms (2-3)
   - Collocations (3-5)
   - Example IELTS sentence

**facilitate** /fəˈsɪlɪteɪt/ (v) - Band 7.5
Definition: To make an action or process easier
Synonyms: enable, assist, help
Collocations: facilitate communication, facilitate access, facilitate learning
IELTS Example: "Technology can facilitate collaboration between remote teams."

2. **Contextual Sentences** (Gap-fill)
   - 20 sentences using the words
   - Academic IELTS style
   - Answers provided

3. **Word Formation Table:**
   | Noun | Verb | Adjective | Adverb |
   |------|------|-----------|--------|
   | facilitation | facilitate | facilitative | - |

4. **Synonym Matching Exercise**

5. **Paragraph Writing Task:**
   Write a 150-word paragraph using minimum 10 target words

6. **Flashcard Format:**
   - Front: Word + example sentence with blank
   - Back: Definition + completed sentence
```

### 3. Language Learning Frameworks[9][10]

**Duolingo (Open Patterns)**:[11][9]
```python
# Duolingo-style gamification implementation
class IELTSLearningPath:
    def __init__(self):
        self.levels = {
            'beginner': {'target_band': 5.0, 'lessons': 50},
            'intermediate': {'target_band': 6.5, 'lessons': 70},
            'advanced': {'target_band': 7.5, 'lessons': 90}
        }
        
    def calculate_xp(self, activity_type, score):
        xp_map = {
            'reading_question': 10,
            'listening_question': 10,
            'writing_task': 50,
            'speaking_practice': 30
        }
        return xp_map[activity_type] * (score / 100)
    
    def award_achievements(self, user_stats):
        achievements = []
        if user_stats['streak_days'] >= 7:
            achievements.append('🔥 Week Warrior')
        if user_stats['completed_tasks'] >= 50:
            achievements.append('📚 Dedicated Learner')
        if user_stats['practice_band'] >= 7.0:
            achievements.append('⭐ Band 7 Achiever')
        return achievements
```

**Memrise Pattern**:[10]
```javascript
// Spaced repetition system for vocabulary
class VocabularyReviewSystem {
  constructor() {
    this.intervals = [1, 3, 7, 14, 30]; // days
  }
  
  calculateNextReview(word, correct) {
    const currentInterval = word.reviewInterval || 0;
    
    if (correct) {
      // Move to next interval
      const nextIndex = this.intervals.indexOf(currentInterval) + 1;
      word.reviewInterval = this.intervals[nextIndex] || 30;
    } else {
      // Reset to beginning
      word.reviewInterval = 1;
    }
    
    word.nextReviewDate = new Date();
    word.nextReviewDate.setDate(
      word.nextReviewDate.getDate() + word.reviewInterval
    );
    
    return word;
  }
  
  getDueWords(userWords) {
    const today = new Date();
    return userWords.filter(word => 
      new Date(word.nextReviewDate) <= today
    );
  }
}
```

### 4. Free Speech Recognition APIs[12][13]

**Web Speech API (Browser Native)**:
```javascript
// Free browser-based speech recognition for Speaking practice
class IELTSSpeakingPractice {
  constructor() {
    this.recognition = new (window.SpeechRecognition || 
                           window.webkitSpeechRecognition)();
    this.recognition.continuous = true;
    this.recognition.interimResults = true;
    this.recognition.lang = 'en-US';
  }
  
  async startRecording() {
    return new Promise((resolve, reject) => {
      this.transcript = '';
      
      this.recognition.onresult = (event) => {
        let interimTranscript = '';
        let finalTranscript = '';
        
        for (let i = event.resultIndex; i < event.results.length; i++) {
          const transcript = event.results[i][0].transcript;
          if (event.results[i].isFinal) {
            finalTranscript += transcript + ' ';
          } else {
            interimTranscript += transcript;
          }
        }
        
        this.transcript = finalTranscript;
        this.updateUI(finalTranscript, interimTranscript);
      };
      
      this.recognition.onend = () => {
        resolve(this.transcript);
      };
      
      this.recognition.start();
    });
  }
  
  async analyzeResponse(transcript, expectedKeyPoints) {
    // Check for key vocabulary
    const vocabularyScore = this.checkVocabulary(transcript);
    
    // Check grammar (basic patterns)
    const grammarScore = this.checkGrammar(transcript);
    
    // Check fluency (word count, pauses)
    const fluencyScore = this.checkFluency(transcript);
    
    // Check content coverage
    const contentScore = this.checkContent(transcript, expectedKeyPoints);
    
    return {
      overall: (vocabularyScore + grammarScore + fluencyScore + contentScore) / 4,
      breakdown: {
        vocabulary: vocabularyScore,
        grammar: grammarScore,
        fluency: fluencyScore,
        content: contentScore
      },
      feedback: this.generateFeedback(transcript)
    };
  }
  
  checkVocabulary(text) {
    const advancedWords = [
      'facilitate', 'demonstrate', 'significant', 
      'consequently', 'moreover', 'nevertheless'
    ];
    
    const foundWords = advancedWords.filter(word => 
      text.toLowerCase().includes(word)
    );
    
    return (foundWords.length / advancedWords.length) * 100;
  }
}
```
