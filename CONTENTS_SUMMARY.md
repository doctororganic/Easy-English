## 🚀 **Quick Start Instructions:**

1. **Download** the `English-Learning-Platform-Purple-Theme.zip` file
2. **Extract** to your desired location
3. **Navigate** to the `english-learning-platform` folder
4. **Install** dependencies: `npm install` or `pnpm install`
5. **Run** locally: `npm run dev` or `pnpm dev`
6. **Build** for production: `npm run build` or `pnpm build`

## 🌐 **Deployment Options:**

### **Option 1: GitHub Pages**
1. Push code to GitHub repository
2. Enable GitHub Pages in repository settings
3. Deploy from `main` branch `/docs` folder

### **Option 2: Netlify**
1. Connect GitHub repository to Netlify
2. Set build command: `npm run build`
3. Set publish directory: `dist`

### **Option 3: Vercel**
1. Import GitHub repository to Vercel
2. Auto-detected settings (React + Vite)
3. Deploy automatically

### **Option 4: Custom Server**
1. Build: `npm run build`
2. Upload `dist` folder contents to your web server
3. Configure server to serve `index.html` for all routes

## 🔧 **Technology Stack:**
- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom purple theme
- **Backend:** Supabase (Database + Auth + Storage + Edge Functions)
- **Icons:** Lucide React
- **Audio:** Web Speech API + React Speech Kit
- **PDF:** jsPDF + html2canvas
- **Charts:** Recharts
