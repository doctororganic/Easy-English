## 🧪 2. Ready-Made IELTS Exam Generator (copy-paste)

Save as `mcp_ielts_exam.py` → start with `python mcp_ielts_exam.py`

```python
from mcp.server.fastapi import serve
import json, random, base64, os, tempfile
from TTS.api import TTS

# ---- load real IELTS structure (no account) ----
with open("ielts_band9.json", "r", encoding="utf-8") as f:
    POOL = json.load(f)  # free band-9 question pool

# ---- voice-over engine (Arabic + English) ----
tts_en = TTS(model_name="tts_models/en/ljspeech/tacotron2-DDC")
tts_ar = TTS(model_name="tts_models/ar/fairseq/vits")

# ---- generate full exam ----
def generate_ielts_exam(band_target: int, lang: str = "en"):
    exam = {"listening": [], "reading": [], "writing": [], "speaking": []}
    for section in POOL:
        q = random.choice(section["questions"])
        exam[section["skill"]].append(q)
    # ---- auto-score guide ----
    exam["score_guide"] = {
        "band_5": "Limited user, frequent problems",
        "band_6": "Competent user, some inaccuracies",
        "band_7": "Good user, occasional inaccuracies",
        "band_8": "Very good user, rare inaccuracies",
        "band_9": "Expert user, fully operational"
    }
    return exam

# ---- auto-correct + tips ----
def correct_ielts(answers: dict, exam: dict):
    report = {}
    for skill, user_ans in answers.items():
        model_ans = exam[skill][0]["model_answer"]
        score = len(set(user_ans.split()) & set(model_ans.split())) / len(set(model_ans.split()))
        band = max(5, int(score * 9))
        tips = exam["score_guide"][f"band_{band}"]
        report[skill] = {"band": band, "tips": tips}
    return report

# ---- voice-over (PowerPoint-like) ----
def voice_lesson(lesson_md: str, lang: str):
    audio_path = tempfile.mktemp(suffix=".wav")
    if lang == "ar":
        tts_ar.tts_to_file(text=lesson_md, file_path=audio_path)
    else:
        tts_en.tts_to_file(text=lesson_md, file_path=audio_path)
    with open(audio_path, "rb") as f:
        return base64.b64encode(f.read()).decode()

# ---- serve ----
serve([generate_ielts_exam, correct_ielts, voice_lesson], port=8000)
```

## 🧑‍🎓 4. Student Profile (JSON file, no DB)

**`pages/profile.tsx`**
```tsx
import { useState, useEffect } from "react";
import { Low } from "lowdb";
import { JSONFile } from "lowdb/node";

const adapter = new JSONFile("db.json");
const db = new Low(adapter, { students: [] });

export default function Profile() {
  const [form, setForm] = useState({ name: "", age: "", goal: "", notes: "" });

  useEffect(() => {
    db.read().then(() => setForm(db.data.students[0] || {}));
  }, []);

  const save = async () => {
    db.data.students = [form];
    await db.write();
    alert("Saved ✔");
  };

  return (
    <div className="bg-bg dark:bg-black text-primary dark:text-accent p-6">
      <h1 className="text-2xl font-bold mb-4">
        {locale === "ar" ? "الملف الشخصي" : "Profile"}
      </h1>
      <input placeholder={locale === "ar" ? "الاسم" : "Name"} value={form.name} onChange={(e) => setForm({ ...form, name: e.target.value })} />
      <input type="number" placeholder={locale === "ar" ? "العمر" : "Age"} value={form.age} onChange={(e) => setForm({ ...form, age: e.target.value })} />
      <textarea placeholder={locale === "ar" ? "الهدف من الاختبار" : "Goal from exam"} value={form.goal} onChange={(e) => setForm({ ...form, goal: e.target.value })} />
      <textarea placeholder={locale === "ar" ? "ملاحظات" : "Notes"} value={form.notes} onChange={(e) => setForm({ ...form, notes: e.target.value })} />
      <button onClick={save} className="bg-primary text-black px-4 py-2 rounded">Save</button>
    </div>
  );
}
```

## 🧠 5. Expert Prompts (copy → paste → generate)

### A. **IELTS Exam Generator Prompt**
```
Act as an IELTS examiner.  
Create 1 full computer-based exam (Listening 40 Q, Reading 40 Q, Writing 2 tasks, Speaking 3 parts)  
Band descriptors 5–9 must be embedded.  
Output JSON only, no markdown.  
Language: English + Arabic translation for prompts.  
Difficulty: band 6.5 target.  
Include model answers + 3-line tip per task.
```

### B. **Voice-Over Lesson Prompt**
```
Create a 10-slide PowerPoint-style lesson for IELTS Writing Task 2.  
Each slide = 1 sentence + 1 bullet.  
Provide Arabic voice-over text (MSA) and English voice-over text.  
Theme: black/green/yellow.  
End with 3 practice questions + model answers.
```

### C. **Auto-Correction Prompt**
```
You are an IELTS band 9 examiner.  
Student answer: {text}  
Model answer: {model}  
Give:  
1. Band (5–9)  
2. 3-line tip (Arabic + English)  
3. Highlight 2 mistakes (diff color)  
Output JSON only.
```
